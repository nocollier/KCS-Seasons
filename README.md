# Repertoire by Season for the Knoxville Choral Society

Encoded as a simple yaml file, can be parsed into different formats.

### Questions

- I put them in yaml files which are meant to be a record of history (which concerts, performance locations, which groups, what pieces). From this I can write code to generate any kind of report or repertoire list we need. What would you like to see?
